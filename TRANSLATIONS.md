# Translation Notes

Curated notes for non-obvious translation choices in `dict/en.json` and `dict/fr.json`. Add an entry whenever a translation is non-trivial or potentially debatable.

## Conventions

- `NAV` (Hungarian tax authority) — kept as `NAV` in both EN and FR. It's a proper noun.
- `ÁFA` → EN `VAT`, FR `TVA`. Standard fiscal terms.
- `ügyfél` / `partner` → EN `customer` / `partner`, FR `client` / `partenaire`.
- `bizonylat` → EN `document`, FR `document`. Generic Hungarian fiscal term covering invoices, receipts, delivery notes, etc.
- `bizonylattömb` → EN `document block` / `invoice block`, FR `bloc de bizonylats` ... TBD per context.

## Decisions log

- 2026-04-29 — `Díjbekérő` → EN `Proforma invoice`, FR `Facture proforma`. Hungarian `díjbekérő` is literally a "fee request" — closest international equivalent is a proforma invoice. `Payment request` was considered but is too generic and would clash with `Fizetési kérelem`.
- 2026-04-29 — `Stornó` / `Stornózás` → EN `Cancellation` / `Cancel document`, FR `Annulation` / `Annuler le document`. The word "storno" is Italian/German commercial vocabulary embedded in Hungarian accounting law. Kept the concept but used natural-language equivalents; avoided the loanword "storno" in EN/FR as it would be opaque.
- 2026-04-29 — `Bizonylattömb` → EN `Invoice block`, FR `Bloc de documents`. A Hungarian fiscal concept: a numbered pre-printed book of document forms. `Invoice block` is a compromise — `document block` is more accurate but less recognisable in a billing UI context. For standalone `Bizonylattömb` entries used `Invoice block`; for `Bizonylattömbök` (plural) and contexts mentioning generic document types, used `Bloc de documents`.
- 2026-04-29 — `Teljesítés` → EN `Performance / Delivery`, FR `Exécution / Livraison`. In Hungarian fiscal law, `teljesítés` is the "date of supply/performance" on an invoice (a VAT concept). No single English word covers both service delivery and goods delivery equally well; the slash form was chosen so the user understands the scope. In narrower contexts (`Teljesítés dátuma`) `Completion date` was used.
  **Superseded on 2026-08-03** — see the slash-gloss entry below; `Teljesítés` is now a single term.
- 2026-04-29 — `Módosító számla` → EN `Corrective invoice`, FR `Facture rectificative`. Hungarian law uses `módosító számla` (literally "modifying invoice") for what EU VAT Directive calls a "credit note" or "corrective invoice". Chose `Corrective invoice` / `Facture rectificative` over `Credit note` / `Avoir` because the HU concept can represent both upward and downward adjustments.
- 2026-04-29 — `Visszavonás` → EN `Cancel / Revoke`, FR `Annuler / Révoquer`. The verb is used in two distinct UI contexts: revoking an API key or invitation (→ Revoke) and cancelling an action (→ Cancel). Both glosses given with slash notation since the key appears in different widgets.
  **Superseded on 2026-08-03** — see the slash-gloss entry below; `Visszavonás` is now `Revoke` / `Révoquer`.

- 2026-08-04 — **Counted units are covered by placeholder keys, not by enumeration.** `28 nap`
  rendered untranslated on screen while `28 nap múlva` was fine, because the dictionary held
  `:due_days nap múlva` — which the pattern layer generalises to any number — and nothing for the
  bare noun. Eight placeholder keys close the families for every value: `:days nap`, `:days napos`,
  `:days napon belül`, `:days napra`, `:days munkanap`, `:years év`, `:hours óra`,
  `:count karakter`. Hungarian does not pluralise after a numeral and EN/FR do, so `1 nap`,
  `1 hónap`, `1 év`, `1 óra`, `1 munkanap` and `1 karakter` are also added as exact keys — layer 1
  runs before the pattern layer, so the exact singular wins over `:days days`.
  Deliberately **not** added: `Ft`, `TESZOR`, `jegyű`, `sorszámú`, `millió` and ~95 other tokens the
  automatic scan proposed. Most are not counted units at all (it also proposed `vagy`, `Budapest`
  and `adhatsz`, words that merely followed a number inside a sentence), and the rest are fiscal or
  structural terms where a guessed translation would read as confident and be wrong.
- 2026-08-04 — **Two more counted composites, found by sweeping the live DOM.** `0 db kimenő
  számla` and `Utolsó szinkron (1/4):` were the only Hungarian left across 13 authenticated
  screens. Both are the `28 nap` shape: the catalog holds `__PCS__ db kimenő számla`, whose
  placeholder is never substituted at runtime — it is in `dict/_rejected.json` for exactly that
  reason — so no captured key could ever match what the DOM renders. Added `:count db kimenő
  számla` / `:count db bejövő számla` with their `1 db …` singulars, following the existing
  `Bejövő számlák` → `Incoming invoices` / `Factures entrantes`, and
  `Utolsó szinkron (:current/:total):`. French keeps the space before the colon, which the
  language-aware translator composes on its own.
- 2026-08-04 — **`:month hónap` was singular and competed with `:months hónap`.** Both keys exist in
  Billingo's catalog and compile to the same pattern shape, so which one won was arbitrary and
  `2 hónap` came out as `2 month`. The EN value of `:month hónap` is now `:month months`; the exact
  `1 hónap` handles the singular. French needed no change — `mois` is invariable.

- 2026-08-03 — **Slash glosses removed from 17 values.** A value of the form `A / B` on a key that contains no slash was a translator's aid, not UI text: a sortable table header reading `Performance / Delivery` is unreadable, and the new separator-splitting lookup layer compounded it (`Teljesítés / Kelt` came out as `Performance / Delivery / Issued`). One term was chosen per key from Billingo's own usage: `Teljesítés` → `Completion` / `Exécution` (consistent with the shipped `Teljesítés dátuma` → `Completion date` / `Date d'exécution`); `Fiók` → `Account` / `Compte` (a bank branch is `bankfiók`, never bare `fiók`); `Megnevezés` → `Description` / `Libellé` (it is the invoice line-item name column); `Megrendelő` → `Customer` / `Client`; `Árukészlet` → `Inventory`; `Visszavonás` → `Revoke` / `Révoquer`; `Érvénytelenítés` → `Invalidation`; `Eszköz` → `Device` / `Appareil`; `Találat` → `Result`; `Teendő` → `Task`; `Település` → `City` / `Ville`; `Tisztség` → `Position` / `Fonction`; `Pályázat` → `Tender`; plus the public-area types `forduló`, `korzó`, `menedékház`, `pálya`. Keys that genuinely contain a slash (`Adószám / EU adószám`) keep it — that is the source text, not a gloss.

- 2026-08-03 — **Weekday abbreviations were wrong and are now fixed against Billingo's own i18n catalog.** The bundle's `Common.form.Label:{monday…sunday}` gives the authoritative mapping. The dictionary had `Hé` → `Hey` / `Salut` (it is *hétfő*, Monday) and `Ke` → `Wed` / `Mer` (it is *kedd*, **Tuesday**). A shifted date-picker header row is not cosmetic: a user setting a `teljesítés dátuma` or `fizetési határidő` "on Wednesday" was clicking Tuesday, on a document reported to NAV. Now `Hé`→`Mon`/`Lun`, `Ke`→`Tue`/`Mar`, `Cs`→`Thu`/`Jeu`, `Pé`→`Fri`/`Ven`, plus the missing `Sze`→`Wed`/`Mer`, `Sz`→`Sat`/`Sam`, `Va`→`Sun`/`Dim`. Note `Sz` is Saturday and `Sze` is Wednesday — easy to swap.

- 2026-08-03 — **`Rét` was mapped to `Tue` / `Mar` and is not a weekday at all.** The catalog shows it only as a campaign cover image label and as a public-area type (`FlatTax.enum.NatureOfPublicSpace:ret`), i.e. "meadow" → EN `Meadow`, FR `Pré`.

- 2026-08-03 — **`Kft.` and `Zrt.` no longer collapse into the same value.** Both were EN `Ltd.` / FR `SARL`, which is wrong for a `zártkörűen működő részvénytársaság` and made two different legal forms indistinguishable. `Kft.` (korlátolt felelősségű társaság) keeps `Ltd.` / `SARL`; `Zrt.` becomes EN `Private limited company` / FR `Société anonyme non cotée`, next to the existing `Nyrt.` → `Public limited company` / `Société anonyme cotée`. Context checked in the bundle: these appear as `TenderMonitor.enum.Beneficiary:*` picker labels, not as a suffix on a company's legal name, so translating them helps rather than misstating an entity's name.

- 2026-08-03 — **Inventory movement pair.** `Bevételi bizonylat` → EN `goods receipt` / FR `bon d'entrée` and `Kivételi bizonylat` → EN `goods issue document` / FR `bon de sortie`, following the shipped `Bevételezés, Kivételezés, Átmozgatás, Leltár` → `Goods receipt, Goods issue, Transfer, Inventory` / `Réception, Sortie, Transfert, Inventaire`. Not "income"/"withdrawal": these are warehouse stock movements, not cash flows.

- 2026-08-03 — **Taxpayer status labels.** `Köztartozásmentes adózó státusz` → EN `Tax-debt-free taxpayer status` / FR `Statut de contribuable sans dettes fiscales` (aligned on the shipped `Köztartozásmentes adózó`); `Megbízható adózó státusz` → EN `Reliable taxpayer status` / FR `Statut de contribuable fiable`. Both are NAV register statuses shown on the company-info screen.

- 2026-08-03 — **Public-area types (address picker) are translated, and that is safe.** 62 accent-less Hungarian strings were added, most of them `NatureOfPublicSpace` values (`rakpart` → `quay` / `quai`, `dűlő`, `liget`, `puszta`, `hrsz.` → `land reg. no.` / `n° cadastral`, …). They appear in a dropdown the user must understand, and lookup is exact-match on a whole text node, so a type word inside a rendered address is never rewritten — verified: `1051 Budapest, Nádor utca 5.` and `Váci út 1.` both return no translation even though `utca` and `út` are keys. The value stored and sent to NAV stays Hungarian regardless, since the walker only substitutes displayed text.

- 2026-08-03 — **Sentence fragments from `v-html` messages.** 150 keys added that are not whole sentences but the text nodes Billingo produces around an inline `<a>` or `<b>`. They are translated to compose in place: a fragment ending in a Hungarian article carries the article for the following link text, and link-text fragments carry none. Reassembly was verified per entry, e.g. `…must be indicated in the SZJA return on **the** ’53 form, and a change occurring during the year on **the** ’T101E form.` A fragment must therefore never be "tidied up" in isolation — check its siblings first.

- 2026-08-03 — **French typography and elision.** The shipped French uses a **regular** U+0020 before `! ? ; :` and `»` (451 values, zero non-breaking spaces), and the translator now re-composes punctuation with that same character. Apostrophes are straight `'` (U+0027), not `’`. `l'SZJA` is invalid elision — the acronym is read letter by letter, so it is `le SZJA`.

- 2026-08-03 — **Billingo's own English catalog is not a source of Hungarian keys.** The bundle ships an English i18n catalog alongside the Hungarian one, and 1,835 of its values were being captured as if they were Hungarian source strings. They are never rendered while the app runs in Hungarian, so they are excluded. Where the two catalogs align by message path, however, Billingo's official English *is* used as a cross-check and, for 58 entries, lifted verbatim.
- 2026-04-29 — `Megjegyzés` → EN `Note`, FR `Remarque`. `Megjegyzés` can mean "comment", "remark" or "note" depending on context. `Note` chosen for EN (shorter, standard invoice vocabulary); `Remarque` for FR rather than `Note` or `Commentaire` because it is the standard neutral term in French professional documents.
- 2026-04-29 — `Megnevezés` → EN `Name / Description`, FR `Libellé`. In invoice line items `megnevezés` means the line-item description/label. `Libellé` (account/item label) is the correct French accounting term; English uses a slash to cover both field usages.
- 2026-04-29 — `Mégse`, `Partnerek`, `Partner`, `Nyugta`, `Műveletek` retained despite absence from the 4593-entry catalog snapshot. These are core UI chrome (Cancel button, Partners menu, Receipt, Actions menu) explicitly required by the acceptance criteria; their absence from the catalog is likely a scraping gap rather than an indication they don't exist in the product.
- 2026-04-29 — `Kiadás` → EN `Expense`, FR `Dépense`. Could also be `Expenditure` (EN) or `Charge` (FR) in an accounting context, but `Expense` / `Dépense` are the most natural terms for a day-to-day invoicing/bookkeeping UI used by small businesses.
- 2026-04-29 (batch 2) — `Előlegszámla` → EN `Advance invoice`, FR `Facture d'acompte`. Hungarian `előleg` = "advance / deposit". `Advance invoice` is the standard English billing term; `Facture d'acompte` is the standard French equivalent (preferred over `Facture d'avance`).
- 2026-04-29 (batch 2) — `Fordított adózás` / `F.AFA (Fordított ÁFA)` → EN `Reverse charge` / `Reverse charge VAT`, FR `Autoliquidation de TVA` / `TVA en autoliquidation`. EU-standard VAT mechanism terminology. `Fordított` = reversed/inverted. The abbreviated label `F.AFA` retained to match what the UI displays.
- 2026-04-29 (batch 2) — `K.AFA (Különbözeti ÁFA)` → EN `Margin scheme VAT`, FR `TVA sur marge`. `Különbözeti` = "differential/margin". EU VAT Directive Art. 311 margin scheme terminology applied.
- 2026-04-29 (batch 2) — `Bevételezés` / `Kivételezés` → EN `Goods receipt` / `Goods issue`, FR `Réception de marchandises` / `Sortie de stock`. Standard warehouse/logistics vocabulary. `Bevételezés` (literally "receipting") = goods coming into stock; `Kivételezés` (literally "issuing") = goods leaving stock. ISO warehouse terminology used.
- 2026-04-29 (batch 2) — `Szváziföld` → EN `Eswatini`, FR `Eswatini`. The kingdom renamed itself from Swaziland in 2018; modern standard name used.
- 2026-04-29 (batch 2) — `Működő` → EN `Active`, FR `Actif`. In the company-info context `működő` means the company is currently operating. Chose `Active` (same as `Aktív`) rather than `Operating` to keep UI badge vocabulary consistent; these appear in different filter contexts so collision is not a problem.
- 2026-04-29 (batch 2) — `Kintlévő` → EN `Outstanding`, FR `En attente de paiement`. `Kintlévő` = "outstanding receivable" (a debt still owed). EN `Outstanding` is the standard accounts-receivable term; FR `En attente de paiement` (awaiting payment) is more natural than the literal `En souffrance` in a UI context.
- 2026-05-24 (P1 delta — editor + promo capture) — `Pályázat` → EN `grant`, FR `appel à projets`. These are EU/innovation funding calls (`vissza nem térítendő támogatás` = non-repayable grant), so `grant` / `appel à projets` is more accurate than `tender`/`appel d'offres`. `Pályázatfigyelő` → EN `Grant Monitor`, FR `Veille des appels à projets`.
- 2026-05-24 — `Céginfó` / `Céginformáció` → EN `Company Info`, FR `Infos entreprise`. `Partnerfigyelő` / `Partnerfigyelés` → EN `Partner Monitor` / `Partner Monitoring`, FR `Veille des partenaires`. Consistent "Monitor/Veille" family with Grant Monitor and the existing tender-monitor naming.
- 2026-05-24 — `Folyamatos teljesítés` → EN `Continuous performance`, FR `Prestation continue`. The VAT "continuous supply" concept on invoices; follows the existing `Teljesítés` → Performance/Exécution convention.
- 2026-05-24 — `Adattörlő kód` → EN `Data erasure code`, FR `Code d'effacement des données`. Hungarian NAV receipt requirement for durable data carriers (Gov. Decree 726/2020).
- 2026-05-24 — `Technikai felhasználó` → EN `Technical user`, FR `Utilisateur technique`; `aláírókulcs` → `signing key` / `clé de signature`; `cserekulcs` → `exchange key` / `clé d'échange`. NAV Online Számla integration terms. `KAÜ` (Központi Azonosítási Ügynök) kept as proper noun, glossed `Central Authentication Agent` / `Agent d'authentification central`. `adózó` → `taxpayer` / `contribuable`; `Korm. rendelet` → `Government Decree` / `décret gouvernemental`.
- 2026-05-24 — `Közlemény` (bank transaction context) → EN `Payment reference`, FR `Communication`. The free-text note on a bank transfer, not an "announcement". FR `Communication` is the standard bank-transfer field label.
- 2026-05-24 — `ügymenet` / `Ügykezelő` → EN `case` / `case manager`, FR `dossier` / `gestionnaire de dossiers`. Billingo's "dossier" feature (`/n/document/dossier`) groups documents per partner; `case`/`dossier` fits the UI better than literal "course of business".
- 2026-05-24 — Billingo's own postal address (`1054 Budapest, Honvéd utca 8. 1. em. 2. ajtó`) kept verbatim (identity translation) in EN and FR — addresses are not localized. Captured because `Honvéd` carries a HU diacritic.
- 2026-05-24 — Price labels (`3.790 Ft + ÁFA / hó`, `… / év`) — number + `Ft` kept as displayed (incl. NBSP thousands separators); only `ÁFA`→VAT/TVA and `/ hó`→`/ mo`/`/ mois`, `/ év`→`/ yr`/`/ an` localized.
- 2026-05-24 (P1 interactive capture — editor dropdowns) — `ÁKK` kept verbatim (identity) in EN+FR. It is the acronym of the Államadósság Kezelő Központ (Hungarian Govt Debt Management Agency), used as an FX-rate source option alongside MNB; an institution acronym like NAV/MNB, not translated.
- 2026-05-24 — `Tétel közvetlen beszúrása` → EN `Insert item directly`, FR `Insérer une ligne directement`. Option in the invoice-editor item dropdown to add a free line vs. pick from the product catalog. `Tétel` = invoice line item.
- 2026-07-31 (pattern layer) — Keys holding a `:token` (`:type letöltése`, `Új :type`) or a number (`3 db`) are now compiled into runtime patterns, so they also translate the substituted text the app actually renders. Two consequences for translators:
  - **Keep the `:token` in the target string.** A translation that drops it (`Company registration number: :number …` → `""`) cannot be rebuilt from the captured text, and the pattern is discarded.
  - **The grammar of the source pair is reused.** `Új :type` → `Nouveau :type` renders `Nouvelle facture` as `Nouveau facture`, and `3 db` → `3 pièces` renders `1 pièces`. Patterns only fire when no exact key matched, so add the exact key when the agreement matters. For number keys, prefer writing the plural form — the compiler keeps the largest-numbered pair of a given shape for exactly this reason.
- 2026-05-24 — `Kezdd el beírni a keresett cég vagy partner nevét!` → EN `Start typing the name of the company or partner you're looking for!`, FR `Commence à saisir le nom de l'entreprise ou du partenaire recherché !`. Empty-state hint of the partner search combobox.
- 2026-08-03 (dictionary consolidation) — `ÁKK` is **two different acronyms** in Billingo and must be glossed per context. As an FX-rate source it stays verbatim (see the 2026-05-24 entry: Államadósság Kezelő Központ, an institution like NAV/MNB). As a VAT category on a document it is `Áfa körön kívüli` — outside the scope of VAT. The unresolved i18n paths that leak into the DOM are therefore glossed, not translated: `Document.enum.Vat:ÁKK` → EN `ÁKK (outside VAT scope)`, FR `ÁKK (hors champ TVA)`; `Document.enum.Vat:ÁTHK` → EN `ÁTHK (outside territorial scope of VAT)`, FR `ÁTHK (hors du champ territorial de la TVA)`. The NAV code stays the leading token in both languages so a document row remains reconcilable against the NAV VAT categories; the wording of the gloss reuses the existing `ÁFA körön kívüli` and `ÁFA területi hatályán kívül` entries.
- 2026-08-03 — Fixed `Vat:ÁTHK` → EN `VAT:ÁTHK` (was `VAT:ATKH`, a transposed NAV code) and `Vat:ÁKK` → EN `VAT:ÁKK` / FR `TVA:ÁKK`. A transposed fiscal code is worse than an untranslated one: it looks authoritative and does not reconcile.
- 2026-08-03 (public-area types, `közterület jellege`) — The address picker's type list was already ~80 % translated, so the remaining empty entries were filled to match the shipped style (`…sor` → `…row`, `…ház` → `…house`, `…út` → `…road`) rather than left blank. Non-obvious ones: `sávház` → EN `slab block`, FR `immeuble-barre` (an architectural form, not a literal "strip house"); `strandfürdő` → EN `open-air baths`, FR `bains en plein air`; `műút` → EN `paved road`, FR `route revêtue` (a metalled public road — *not* "artificial road"); `összekötés` → EN `link road`, FR `voie de liaison`, deliberately **not** `Connection`, which is the app feature name carried by the capitalised `Összekötés`; `szél` and `széle` → EN `edge`, FR `bord` (the public-area sense, *not* "wind"); `sánc` → `rampart` / `rempart`; `őrházlak` → `guard house dwelling` / `logis de garde`. Safe because layer 1 matches a whole text node, so a standalone type word can never rewrite the type inside a rendered address such as `Váci út 1.`.
- 2026-08-03 — `Billingo` → `Billingo` in both languages (identity). This is not redundant: the tab title renders as `Bejelentkezés - Billingo`, and the translator's separator layer is all-or-nothing — it resolves a split string only when *every* lettered part resolves. Without the brand name as a key the whole title stayed Hungarian. Verified: `Bejelentkezés - Billingo` → `Log in - Billingo` / `Se connecter - Billingo`.
- 2026-08-03 — Dropped 43 foreign-locale date keys (Vietnamese `Tháng 1`–`Tháng 12`, Icelandic `Janúar`/`Ágúst`/`Nóvember`, Czech `únor`/`říjen`, Slovak `úno`, Turkish `Eylül`, French `Décembre`/`Février`, and the Faroese/Swedish/Spanish weekday abbreviations). They are residue from the bundle's multi-locale date catalog and cannot occur in a Hungarian DOM. Two of them also carried values that leaked a language annotation into user-visible text (`únor` → `February (Czech)`) and one was factually wrong (`úno` → `January (Slovak)`; `úno` is February). Every Hungarian month and weekday form — including `Ápr`, `Márc`, `Máj`, `Jún`, `Júl`, `máj.`, `Pé`, `Pén`, `Csü` — was checked key by key and kept.
